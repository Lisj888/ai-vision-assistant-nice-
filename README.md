# 多功能 AI 视觉助手

## 项目简介
这是一个基于通义千问大模型的多功能视觉识别系统。用户可以上传任意图片，选择不同功能，AI 会返回对应结果。

## 功能列表
- 识别数字（手写数字照片）
- 识别植物（拍照识别花草树木）
- 识别动物（拍照识别猫狗鸟等）
- 识别菜名（拍食堂的菜，AI 告诉你是什么）
- 拍照翻译（拍英文，翻译成中文）
- 自由问答（拍任何东西，AI 详细描述）

## 技术栈
- Python 3.10
- Gradio（网页界面）
- Dashscope（通义千问 API 调用）
- 通义千问 qwen-vl-max 视觉大模型

## 运行方式
1. 安装依赖：
   pip install gradio dashscope pillow

2. 在 `ai_vision.py` 中填入你的 API Key（参考阿里云百炼平台）

3. 运行程序：
   python ai_vision.py

4. 浏览器打开 `http://127.0.0.1:7860`，上传图片即可使用。
